# Руководство

Подробности по всем возможностям движка. Быстрый старт и обзор — в [README](../README.md).

## Запуск локально

Windows (PowerShell):

```powershell
cd hashpen
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # в .env поставить SESSION_COOKIE_SECURE=0 и свой SECRET_KEY
flask --app wsgi run
```

Ubuntu:

```bash
cd hashpen
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask --app wsgi run
```

Сайт откроется на http://127.0.0.1:5000. База создаётся сама в `instance/blog.db`.

## Добавление статей пачкой

Положите `.md`-файлы в папку и выполните:

```bash
flask --app wsgi import-md путь/к/папке          # новые статьи; существующие (тот же slug) пропускаются
flask --app wsgi import-md путь/к/папке --update # перезаписать существующие
```

Формат файла — см. `examples/primer-stati.md`. Все поля front matter необязательны:
если нет `title`, берётся первый заголовок `# ...` или имя файла; если нет `date` — дата изменения файла.

## Другие команды

- `flask --app wsgi rebuild` — пересобрать HTML, оглавления и поиск у всех статей.

## Настройки (.env)

| Переменная | Что это |
|---|---|
| `SECRET_KEY` | Случайная строка, обязательно своя |
| `SITE_TITLE`, `SITE_TAGLINE` | Название и подзаголовок |
| `SITE_URL` | Адрес сайта для RSS, sitemap, canonical |
| `CONTACT_EMAIL` | Подставляется в политику конфиденциальности |
| `YANDEX_METRIKA_ID` | Номер счётчика; грузится только после «Принять» в cookie-баннере |
| `SESSION_COOKIE_SECURE` | `1` на сервере с HTTPS, `0` локально |

Политика конфиденциальности — `app/pages/privacy.md` (шаблон, заполните поля в скобках).

## Вход автора

Настраивается один раз, двумя командами. Обе ничего не пишут сами — печатают строки для `.env`.

```bash
flask --app wsgi set-password    # спросит пароль, выдаст ADMIN_PASSWORD_HASH
flask --app wsgi setup-2fa       # выдаст QR-код, ключ, резервные коды и две строки для .env
pip install qrcode               # необязательно: рисует QR-код прямо в терминале
```

Скопируйте три строки в `.env` и перезапустите сайт. Вход — по адресу `/login`:
сначала пароль, потом шесть цифр из приложения-аутентификатора (Google Authenticator, Aegis, 2FAS).
Вместо цифр можно ввести резервный код — каждый работает один раз, сохраните их отдельно от телефона.

Что защищено:

- пароль хранится только в виде хэша (scrypt), в базе его нет;
- один и тот же код из приложения нельзя использовать дважды;
- после 7 неудачных попыток вход с этого IP блокируется на 15 минут;
- формы защищены CSRF-токеном, cookie сессии — `HttpOnly`, `SameSite=Lax`, а при `SESSION_COOKIE_SECURE=1` ещё и `Secure`;
- сессия живёт 30 дней, выход — кнопкой «Выйти» в шапке.

Автор видит черновики (в ленте, поиске и по прямой ссылке), остальные — нет. Черновик помечен в списке серой плашкой.

## Редактор

После входа в шапке появляется кнопка «Написать статью», а на странице статьи — «Редактировать» и «Удалить».

- **Черновик.** Галочка внизу редактора. Черновик виден только автору и помечен плашкой в ленте.
- **Превью.** Вкладка рядом с «Текст» — показывает статью ровно так, как её увидит читатель (рендер идёт на сервере, тем же кодом).
- **Картинки.** Кнопка «Вставить картинку», перетаскивание файла в поле текста или вставка из буфера (Ctrl+V).
  Файл сохраняется в `instance/uploads/ГГГГ/ММ/`, в текст подставляется `![](/uploads/…)`.
  Принимаются PNG, JPEG, GIF и WebP — тип проверяется по содержимому файла, а не по расширению. Ограничение размера — `MAX_UPLOAD_MB` (по умолчанию 10).
- **Адрес статьи.** Если поле пустое, адрес делается из заголовка. При правке заголовка адрес не меняется сам — его можно поменять вручную.
- **Ctrl+S** сохраняет статью. Текст также дублируется в браузере: если вкладка закрылась до сохранения, при возврате в редактор он предложит восстановить черновик.

Удаление спрашивает подтверждение и удаляет статью насовсем; загруженные картинки при этом остаются в `instance/uploads`.

## Поиск и оформление

**Подсветка найденного.** В результатах поиска карточка показывает не начало статьи, а фрагмент вокруг совпадения; найденные слова выделены в тексте и в заголовке. Фрагмент строит сам SQLite (`snippet()` из FTS5).

**Блоки кода.** Язык указывается после открывающих кавычек, и тогда в углу блока появляется его метка:

````
```bash
systemctl restart hashpen
```
````

Без языка код остаётся обычным моноширинным текстом — угадывание отключено намеренно, на коротких фрагментах оно чаще ошибается.

Работают: `bash`, `python`, `sql`, `json`, `yaml`, `ini`, `diff`, `javascript`, `typescript`, `xml`, `css`, `go`, `rust`, `php`, `java`, `c`, `cpp`, `makefile`, `markdown`, `nginx`, `dockerfile`.
Привычные сокращения тоже понимаются: `sh`, `shell`, `console` → bash; `py` → python; `yml` → yaml; `conf` → ini; `html` → xml.

**Ссылки в мессенджерах.** У каждой страницы есть Open Graph-теги: заголовок, отрывок и картинка. Для статьи берётся её первая картинка, если она есть, иначе общая `app/static/og-image.png` (её можно заменить своей, размер 1200×630). У статей также добавлена разметка `JSON-LD BlogPosting` — её читают поисковики.

После обновления кода на сервере нужно пересобрать HTML статей, иначе метки языка появятся только у новых:

```bash
cd /srv/hashpen && sudo -u hashpen .venv/bin/flask --app wsgi rebuild
```

## Отдельные страницы

Страницы вроде «О себе» или «Контактов» живут отдельно от статей: у них нет даты, тегов и времени чтения, они не попадают в ленту, поиск и RSS, но есть в `sitemap.xml` и в «Карте сайта».

- Управление — ссылка **«Страницы сайта»** в сайдбаре (видна только автору) или адрес `/admin/pages`.
- Редактор тот же, что у статей: markdown, превью, картинки, черновик.
- Адрес — короткий, прямо в корне: `/about`, `/contacts`. Служебные имена занять нельзя: `a`, `admin`, `login`, `logout`, `search`, `tag`, `static`, `uploads`, `privacy`, `sitemap`, `sitemap.xml`, `rss.xml`, `robots.txt`, `feed`, `api`, `p`. При попытке редактор покажет ошибку.
- Галочка **«показывать в сайдбаре»** выводит страницу в меню слева, под «Все статьи». Снятая галочка оставляет ссылку только в подвале и на карте сайта.
- Поле **«Порядок»** задаёт место в списке: меньше число — выше. При равных значениях сортировка по названию.

Политика конфиденциальности остаётся файлом `app/pages/privacy.md` — её нельзя случайно удалить из админки.

## Настройки сайта в админке

После входа — «Настройки сайта» в меню слева (`/admin/settings`). Меняются без правки файлов и перезапуска:

- название, подзаголовок, описание для поисковиков, почта для связи;
- номер Яндекс.Метрики;
- цвет акцента отдельно для тёмной и светлой темы и тема по умолчанию;
- своё поле CSS — добавляется в конец стилей и перебивает стандартные правила.

Остальные оттенки акцента (наведение, фокус, подложка тега) считаются из вашего цвета автоматически.
Значения берутся из базы; если настройка ни разу не сохранялась, работает то, что указано в `.env`.
Технические параметры — `SECRET_KEY`, `SITE_URL`, `DATABASE`, пароль и 2FA — остаются только в `.env`.

Свой CSS правит лишь оформление: сломать им текст или работу сайта нельзя, а кнопка «Очистить свой CSS» возвращает стандартный вид.

## Версии базы

Схема версионируется прямо в SQLite (`PRAGMA user_version`), шаги лежат в `app/migrations.py`.
При запуске приложение само доводит базу до последней версии; вручную — `flask --app wsgi db-upgrade`.

Чтобы изменить схему, добавьте в конец списка `MIGRATIONS` шаг с новым номером. Уже выпущенные шаги править нельзя — на работающих базах они применены.

## Установка на новый сервер

На чистой Ubuntu всё делается одной командой из папки проекта:

```bash
sudo bash install.sh
```

Скрипт спросит домен, название сайта и имя службы, а дальше сам: поставит пакеты, заведёт системного пользователя, создаст окружение и `.env` со случайным `SECRET_KEY`, накатит базу, настроит systemd и nginx (включая отдачу статики и картинок), пропишет ежедневный бэкап и проверит, что сайт отвечает. Повторный запуск безопасен: `.env` и база не перезаписываются.

Останется два шага, которые скрипт напечатает в конце: `setup-auth.py` для пароля и 2FA, и `certbot` для сертификата.
